# Aloka质量检测平台 (Aloka QA System)

本地部署的旅游顾问对话 / Bot 行程方案质检平台。围绕一份《需求测试题库》工作：每个案例自带「埋的坑」与「正确应对」作为评分底牌，平台据此对 Bot 产出的行程方案进行**避坑评测**。

> 纯本地运行，不依赖任何外部服务。仅在启用「真实 Bot 评测 / LLM 语义裁判」时才需要你自备一个 OpenAI 兼容的模型 API Key。

---

## 功能特性

### 避坑评测 · 融合三层（核心）
把题库「正确应对」拆成结构化「避坑断言」，三层融合打分：
1. **红线零容忍**：致命项（安全 / 非法驾驶 / 证件 / 闭馆撞期）遗漏即一票否决，整案判 0 分；
2. **8 维等权命中率**：证件合规 / 时间窗口 / 预订限流 / 交规地方法规 / 安全健康 / 地理动线 / 费用陷阱 / 人群适配；
3. **LLM 语义裁判**：逐条判命中 / 遗漏 + 证据原句 + 置信度（置信度 < 0.6 的命中降级为遗漏并标待复核）。
- 输出：避坑得分、断言命中率、致命遗漏计数、8 维命中率、逐条命中 / 遗漏清单。

### Bot 自动化测试（Playwright + CDP）
- **手动模式**：一键「全新注册并启动」——自动生成不重复手机号 → 填验证码 → 随机资料 → 进入聊天页 → 选案例发题 → 抓回答 → 自动评分。
- **自动模式（无人值守）**：从注册到评分全自动，支持 **10 窗口并发**（独立 CDP 端口 9323-9332 与独立 profile），题目按序分发，错峰启动。
- **智能交互兜底**：
  - Bot 反问 → 按规则自动补全（日期选未来、A/B/C 选具体答案）；
  - Bot 弹 A/B/C/D 选项按钮 → 自动点**最新一组**的 A（带指纹去重，旧组残留不误点）；
  - 授权弹窗 → 自动点「始终允许」；
  - Bot「处理中…」状态检测：处理中不判完成、顺延等待，避免把半成品当最终答案评分。

### 平台功能
- **质检看板**：综合平均避坑得分、8 维最低命中率、致命遗漏总数、有效样本、最新评测；评分趋势柱状图（红黄绿分级）+ 八维命中率条形图 + 最近评测记录（点击查看详情）。
- **质检报告**：历次评测完整记录，详情弹窗含案例快照、逐条断言裁决（命中/遗漏/证据/置信度）、Bot 原始回答；支持导出 JSON、清空（二次确认）。
- **案例库**：对齐《需求测试题库》三轴（目的地×时段 / 服务类型 / 坑类型），支持上传题库、AI 造题、坑类型词表预览与编辑。
- **管理员鉴权**：Flask session + pbkdf2 密码哈希，可设 / 改 / 删登录密码。
- **深色 / 浅色双主题**：设置页一键切换。

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
playwright install chromium   # Bot 自动化测试需要
```

### 2. 启动

- **Windows**：双击 `start.bat`
- **macOS / Linux**：`./start.sh`
- 或手动：

```bash
python server.py          # Windows
python3 server.py         # macOS / Linux
```

启动后访问 **http://localhost:8501**。

> 首次运行 `settings.json` 不存在时，平台处于**免登录开放态**（方便本地试用）。进入「设置」页可设置管理员密码；设密码后重启即需登录。

## 配置（可选）

复制模板并填入你的模型 Key：

```bash
cp settings.example.json settings.json
```

| 字段 | 说明 |
|---|---|
| `judge_api_key` | 裁判 / 生成模型 API Key（OpenAI 兼容） |
| `judge_base_url` | 模型服务地址 |
| `judge_model` | 裁判模型名 |
| `generator_model` | 生成模型名（留空则用 judge_model） |
| `bot_wait_ms` | Bot 回答等待时长（毫秒，默认 120000） |
| `bot_input_selector` / `bot_send_selector` / `bot_answer_selector` | Bot 页面选择器（探测后自动保存） |
| `sample_times` | 轻量裁判采样次数 |

> ⚠️ `settings.json` 含密钥，**已被 `.gitignore` 排除，不会进入版本库**。

## 使用说明

1. **案例库**：上传题库或点「AI 造题」合成新案例；「坑类型词表」入口可预览 / 编辑一级 / 二级坑类型。
2. **质检系统 · 手动模式**：点「全新注册并启动」打开 Bot 聊天页 → 选案例发题 → Bot 反问 / 选项 / 授权全自动兜底 → 出避坑得分与逐条清单。
3. **质检系统 · 自动模式**：设窗口数（≤10）、评测条数、起始序号 → 启动后从注册到评分全自动无人值守，进度 / KPI / 结果日志实时可见。
4. **质检报告**：点开任意记录查看案例快照、逐条断言裁决与 Bot 原始回答；支持导出 JSON / 清空。
5. **质检看板**：实时汇总平均得分、最弱维度、致命遗漏与趋势柱状图。
6. **设置**：改登录密码、裁判模型 Key、切换深色 / 浅色主题。

## 评分标准速览

| 指标 | 计算方式 |
|---|---|
| 避坑得分 | 8 大维度命中率**等权算术平均**（0~100%） |
| 维度命中率 | 该维度命中条数 ÷ 该维度已判定条数 |
| 断言命中率 | 全部命中 ÷ 全部已判定（辅助参考，不参与定分） |
| 致命遗漏 | 遗漏的致命断言条数；**> 0 即触发红线，避坑得分强制归 0** |
| 低置信降级 | 裁判判命中但置信度 < 0.6 → 计为遗漏并标待复核 |
